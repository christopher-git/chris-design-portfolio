Developer Portal: A Self-Service API Hub

Centralizing API access, documentation, and key management into a single portal — cutting integration time and eliminating manual walkthroughs.

Design Leadership · UX Design · API Strategy

The problem

FourKites offers a large suite of APIs and webhooks so customers, carriers, and partners can integrate with the platform in both directions. Before the Developer Portal existed, getting a new integration live meant scheduling meetings with our implementation and operations teams, who walked partners through the API spec manually and shared documentation as offline files. That overhead sat on every single integration, and API tiers had no self-service access control layer to manage who could reach what.

What we built

A centralized, self-service developer portal: a one-stop hub for any FourKites user to manage their integration in both directions, generate and manage API keys, and browse documented, tiered API bundles without opening a ticket. The project spanned UX design, information architecture for the docs, and the access-control/bundling strategy that determines which capabilities a given account tier can reach.

Design approach

The portal is built around four things developers actually need on day one: a centralized access point for their team, an exhaustive but navigable data source for complex integrations, self-serve customization of which API bundles they can use, and documented, guided key generation — all included free with a FourKites subscription.

Impact

The portal replaced offline documentation hand-offs with a self-service flow, cutting the time our implementation and operations teams spent walking partners through API specs and freeing them to spend that time on higher-value pre-sales and pilot work. It also gave the sales and pilot process a stronger story to tell during pre-sales conversations — prospective customers could explore the actual API surface themselves instead of relying on a slide deck. The Developer Portal was nominated for the 2021 Devportal Award across three categories: Best Use of API Gateway Integration, Best API Reference Documentation & Support, and Best Designed Application.
